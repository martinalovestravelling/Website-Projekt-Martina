01 — STARTING POINT 01 — AUSGANGSLAGE

Why build it this way Warum so gebaut

The site itself needed to match what it's about: process first, then AI — not a framework bolted onto undefined content. It also had to be something one person could build and keep maintaining solo, without a development team or a recurring hosting bill. Die Seite sollte selbst zeigen, wofür sie steht: erst Prozess, dann KI – kein aufgesetztes Framework über unklarem Inhalt. Außerdem musste sie von einer Person allein gebaut und gepflegt werden können, ohne Entwicklungsteam und ohne laufende Hosting-Kosten.

That pointed to a static site: plain HTML and CSS, served for free by GitHub Pages, with no server to maintain and no build step to break. Working with Claude Code as an AI pair-programmer made that realistic across many rounds of content and design changes — as long as the process stayed disciplined: a written brief first, code only once the brief was clear. Das sprach für eine statische Seite: reines HTML und CSS, kostenlos über GitHub Pages ausgeliefert, ohne Server zum Warten und ohne Build-Schritt, der brechen kann. Mit Claude Code als KI-Pair-Programmer wurde das über viele Inhalts- und Design-Runden hinweg realistisch – solange der Ablauf diszipliniert blieb: erst das schriftliche Briefing, Code erst, wenn das Briefing klar war.

04 — LEARNINGS 04 — LEARNINGS

What this project taught me Was dieses Projekt gezeigt hat

01

Write the brief before the promptErst das Briefing, dann der Prompt

A document that states the facts and the rules up front heads off invented content far more reliably than catching it after the fact.Ein Dokument, das Fakten und Regeln vorab festhält, verhindert erfundene Inhalte zuverlässiger, als sie im Nachhinein zu korrigieren.

02

Name the exception, don't hide itDie Ausnahme benennen, nicht verstecken

The two places this site does use JavaScript — a chat widget and a language-preference toggle — are each scoped to one small file and documented, instead of quietly becoming a precedent for more.Die beiden Stellen, an denen diese Seite doch JavaScript nutzt – ein Chat-Widget und eine Sprachpräferenz – sind jeweils auf eine kleine, dokumentierte Datei begrenzt, statt stillschweigend zum Vorbild für mehr zu werden.

03

Fix the root cause, not the symptomDie Ursache beheben, nicht das Symptom

A sticky header that vanished on scroll got patched twice as a layout tweak before the real cause turned up: a sticky element only holds within its parent's box, and that parent was too short.Ein beim Scrollen verschwindender Sticky-Header wurde zweimal als Layout-Anpassung „repariert", bevor die eigentliche Ursache auftauchte: Ein Sticky-Element hält nur innerhalb der Box seines Elternelements – und die war zu kurz.

04

A dated log keeps solo, AI-assisted work honestEin datiertes Protokoll hält KI-unterstützte Einzelarbeit ehrlich

Across many rounds of edits, one running, dated log of decisions is what lets a single person — and the agent — stay oriented, instead of relying on memory of what was tried before.Über viele Änderungsrunden hinweg sorgt ein einziges, laufend datiertes Entscheidungsprotokoll dafür, dass eine einzelne Person – und der Agent – orientiert bleiben, statt sich auf die Erinnerung an frühere Versuche zu verlassen.
